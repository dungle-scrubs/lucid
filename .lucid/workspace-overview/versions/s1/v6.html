Lucid Workspace Overview

Agent-agnostic CLI for addressable HTML artifacts and located agent-human review

Artifact: the free-form HTML page you're viewing right now — generated by the agent, reviewed by you.

Status

Version0.1.0
StatusMVP
RuntimesBun, TypeScript 5.9
StackEffect (CLI), Lit + Shadow DOM (overlay)

Core Features

  • Addressable surface — every element and text range in the artifact is targetable by annotation
  • Located feedback loop — human markup flows back to the agent via append-only NDJSON event log
  • Per-session loopback server — independent port and origin per artifact session
  • Layered anchors — lucidId → fingerprint → DOM path, with quote-based text range resolution
  • Orphaned handling — failed re-attachment surfaces in orphan tray, never silently drops feedback
  • Cross-agent resume — any harness calls lucid wait <file> with no cursor to get full folded state from the append-only NDJSON event log, then continues iterating

CLI Commands

CommandPurpose
lucid open <file>Serve the artifact (HTML page), open viewer in browser, return opening cursor
lucid wait <file>Block until human submits annotations/messages, then return them as JSON for the agent to consume
lucid end <file>End session, stop server

Deferred (Post-MVP)

  • Diff/revert UI between versions
  • Inbound image paste in annotations
  • Layout audit and polish
  • Auth/token hardening — only relevant if non-loopback binding is ever added (current design intentionally binds to 127.0.0..only)
  • Multi-artifact per session

Project Layout

src/cli/Effect CLI entry, commands, daemon spawn
src/core/Event log, fold, versions, watcher, cursor, lock
src/server/Per-session loopback server: serves artifact HTML, injects overlay+chrome, watches for file changes to commit versions, handles annotation/message POSTs from browser
src/anchors/Anchor schema, DOM capture and resolution
client/Browser bundle: overlay + chrome (Lit)
