Workspace Overview

A scratch artifact used to exercise the Lucid chrome - tabs, sidebar, and the annotation loop.

Areas

  • Chrome: React + assistant-ui shell, shadcn (Base UI variant) sidebar and tabs.
  • Overlay: Lit-based annotation layer injected over the artifact.
  • Transport: Bun.serve per-session loopback server.
  • Anchors: shared linkedom resolver mapping annotations to elements and text ranges.
