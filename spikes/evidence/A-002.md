## Observations

- **SessionStart announce: CONFIRMED.** `announce.log` records session
  `ac0654bc-...` with concrete transcript path
  `~/.claude/projects/-Users-kevin-dev-lucid-v2-spikes-a002-hooks/ac0654bc-...jsonl`.
  This is the adapter's attach signal - identity + where to tail, delivered
  at session start with zero agent cooperation.
- **PostToolUse mid-turn injection: CONFIRMED.** `delivery.log` shows two
  `delivered_by: PostToolUse` events; `FEEDBACK-ONE-APPLIED` appears in the
  pty; the delivery occurred between two Write calls of a single turn. This
  is the strongest injection mode - it does not wait for the turn to end.
- **Terminal continuity: CONFIRMED.** After both injections, turn 3
  ("still alive") was served and the session exited on its own. No takeover.
- **Hook isolation (D-025) works end to end.** `--setting-sources project`
  + `HERDR_ENV` unset ran a full multi-turn session with no `0/4` Stop-hook
  hang; the machine-global hooks were excluded, the project hooks retained.
- **Stop-hook path: PARTIAL.** Turn 2 was meant to be tool-free so the Stop
  hook would deliver, but the model used a Write, so PostToolUse delivered
  feedback-two first (243.203). The Stop block-continue redrive was seen in
  an earlier un-isolated run ("Ran 4 stop hooks / Stop hook error: HUMAN
  FEEDBACK (turn end)") but is not cleanly isolated here. Recorded as
  observed, not proven - it is a secondary delivery mode; boundary inject is
  the one that matters and is proven.
